# Branding

## App icon

The current icon is a **placeholder** (see `icon-placeholder.svg` and the icon
generated by `scripts/make-icon.sh`). It is an honest stand-in: a neutral tile
with the `McD` wordmark and a download arrow. It is labelled as temporary on
purpose, not disguised as final.

To replace it:

1. Add a 1024x1024 PNG (or a full `.iconset`).
2. Either drop an `AppIcon.icns` at `assets/AppIcon.icns`, or edit
   `scripts/make-icon.sh` to render the real artwork.
3. The release workflow picks up `assets/AppIcon.icns` automatically.

## Wordmark

`McD` in the system font (SF Pro) for now. A real wordmark is a design task to be
done later; the placeholder keeps the build honest in the meantime.
